## 📌 Featured Project

### 🔹 [v2x](https://github.com/PouyaKhDev/v2x)

**Description:**  
v2x finds, filters, and extracts high‑quality V2Ray configs from Telegram channels and generates subscription files for apps like **V2rayNG**, **Matsuray**, **Hiddify**, and more.  
The subscription files are automatically updated every **20 minutes**, keeping configurations fresh and usable.

**Highlights:**
- Automated scraping and filtering from multiple Telegram channels  
- Periodic updates for subscription files  
- Practical, real‑world utility for users of V2Ray‑based tools
